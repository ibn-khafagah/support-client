# دليل سريع بالعربية – ibnkhafagah/support-client

حزمة Laravel تجعل مستخدمي نظامك يفتحون **تذاكر الدعم الفني** ويتابعونها من داخل النظام نفسه، وتصل التذاكر إلى نظام
**CRM ابن خفاجة** ومعها تفاصيل الصفحة والمستخدم وآخر خطأ تلقائياً، وتظهر ردود فريق الدعم داخل النظام.

## ما الذي تحصل عليه

- **شاشات جاهزة** (Blade) للقائمة والتذكرة الجديدة وصفحة التذكرة والرد والإغلاق والمرفقات – عربية من اليمين لليسار
  وإنجليزية تلقائياً حسب لغة التطبيق.
- **وضع JSON لكل المسارات**: واجهة React أو Vue أو تطبيق موبايل تبني شاشاتها على نفس المسارات، والمفتاح لا يغادر الخادم.
- **تفاصيل تلقائية** مع كل تذكرة: اسم التطبيق وإصداره، الصفحة، المتصفح ونظام التشغيل، دور المستخدم، مرجع آخر خطأ.
- **زر «الإبلاغ عن هذه المشكلة»** لصفحة الخطأ 500.
- **عداد غير المقروء** وحدث `TicketUpdated` لإشعاراتك الخاصة، عبر webhook موقّع أو مزامنة دورية لسجل التغييرات.
- **صندوق صادر**: إذا انقطع الإنترنت أو الـ CRM تُحفظ التذكرة وتُرسل تلقائياً مرة واحدة فقط.
- **احترام حالة الدعم**: عند انتهاء خطة الدعم تظهر رسالة ورابط التجديد، وتبقى تذاكر الفواتير متاحة.

## التركيب في 5 خطوات

1. التثبيت:
   ```bash
   composer require ibnkhafagah/support-client
   ```
2. القيم في `.env` (المفتاح من مقدّم الخدمة – يظهر مرة واحدة في الـ CRM ← العميل ← «الأنظمة المتصلة»):
   ```dotenv
   SUPPORT_API_URL=https://crm.ibnkhafagah.com
   SUPPORT_API_KEY=cs_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   SUPPORT_WEBHOOK_SECRET=
   SUPPORT_APP_NAME="نظامي"
   SUPPORT_APP_VERSION=1.0.0
   ```
3. بوابة «مدير الدعم» (من يرى كل تذاكر الشركة) في `AppServiceProvider::boot()`:
   ```php
   Gate::define('support-admin', fn ($user) => (bool) $user->is_admin);
   ```
4. تأكد أن المجدول يعمل كل دقيقة (`php artisan schedule:list` يعرض `support:flush` و`support:sync`).
5. افتح `/support` وأنت مسجل الدخول، وأرسل تذكرة تجريبية من `/support/create`.

رابط في قائمة نظامك مع العداد:

```blade
<a href="{{ route('support-client.index') }}">الدعم الفني <x-support-badge /></a>
```

## أسئلة شائعة

- **خادمي داخل المكتب وليس له عنوان عام؟** اترك `SUPPORT_WEBHOOK_SECRET` فارغاً: الحزمة تقرأ سجل التغييرات كل 5 دقائق
  باتصال صادر فقط.
- **أين تُحفظ التذاكر؟** في الـ CRM فقط؛ لا جداول في قاعدة بيانات نظامك. صندوق الصادر وحده يُحفظ مؤقتاً في
  `storage/app/support-client`.
- **من يرى التذاكر؟** كل مستخدم يرى تذاكره فقط، ومن تسمح له بوابة `support-admin` يرى كل تذاكر النظام.
- **الأمان؟** المفتاح في `.env` الخادم فقط، لا يظهر في أي صفحة أو رد أو سجل، والاتصال HTTPS إلزامي.
